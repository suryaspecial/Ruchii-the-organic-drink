# 🍹 Ruchii. — The Organic Drink

A modern, responsive landing page for **Ruchii.**, a fictional organic fruit drink brand. The website focuses on a clean visual design, smooth scrolling, engaging animations, and a responsive user experience across desktop, tablet, and mobile devices.

🔗 **Live Website:** https://suryaspecial.github.io/Ruchii-the-organic-drink/

---

## ✨ About the Project

**Ruchii.** is a front-end web development project created to explore modern website design, responsive layouts, smooth scrolling, and scroll-based animations.

The website presents an organic drink brand through a visually engaging landing page featuring product highlights, the production process, product cards, and a brand-focused blog section.

The project was built from scratch using HTML, CSS, Bootstrap, and JavaScript, with GSAP and Lenis used to create a smoother and more interactive scrolling experience.
